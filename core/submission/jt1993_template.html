The sample uses historical NYSE/AMEX classifications (exchange codes 1/2) and common shares (share codes 10/11). Monthly stock returns are compounded from CRSP daily returns. Earlier data initialize rankings and overlapping positions before January 1965. Q1-4 / Sample filters

Sample-selection and data-availability rules

The baseline replication uses CRSP ordinary common shares listed on the NYSE and AMEX. Following the supplied WRDS reference implementation, the following sample-selection and data-availability rules are applied:

  1. Exchange membership. Eligible observations have exchange codes EXCHCD = 1 or 2. Exchange membership is determined using the historical classification valid on each observation date.
  2. Security type. The sample is restricted to ordinary common shares with SHRCD = 10 or 11. This restriction excludes American Depositary Receipts (ADRs) and securities classified by CRSP as real estate investment trusts (REITs). ADR classifications include share codes 30 and 31, while REIT classifications include codes 18 and 48. These restrictions follow CRSP’s share-code definitions.
  3. Sample period. Reported portfolio returns cover January 1965 through December 1989. Earlier observations, beginning in July 1962, supply the return history required for portfolio ranking and overlapping holding cohorts.
  4. Availability of ranking returns. For Table I, Panel A, a stock must have valid returns for J consecutive months preceding portfolio formation. For Panel B, the ranking window excludes the five trading days immediately preceding the holding month. A stock’s observed history must span the relevant ranking window and contain at least one valid daily return within it. Stocks without a valid ranking signal are excluded from that formation’s portfolios.
  5. Return validity. Missing, nonfinite, and below −100% returns are treated as unavailable; valid −100% returns are retained. Missing monthly ranking returns are not replaced with zero. During the holding period, portfolio averages are calculated using constituents with available returns.

Additional availability requirements apply to Tables II and VII. For Table II, market capitalization is calculated using finite, positive absolute prices and shares outstanding. Observations with unavailable capitalization are omitted from size calculations while remaining eligible for return portfolios. For Table VII, formation cohorts are selected to provide complete 36-month calendar follow-up windows within the sample. This requirement applies to cohort timing and does not require every constituent stock to survive for 36 months.
