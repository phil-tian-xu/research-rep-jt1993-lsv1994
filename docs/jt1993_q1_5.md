# HW1 Q1-5: Fama-French three-factor regression

Run these separately from the project root:

```powershell
.\.venv\Scripts\python.exe -u data_prepare_ff3.py
.\.venv\Scripts\python.exe -u main_jt1993_ff3.py
```

`data_prepare_ff3.py` downloads the full monthly US factor series from the
[Kenneth French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html).
No WRDS login is required. The original ZIP, normalized Parquet, and JSON
provenance are stored in `data/raw/ff3/`. Annual rows are excluded and percent
returns are converted to decimals. Missing-value codes remain missing.
`refresh_data=False` reuses the saved vintage; `True` explicitly downloads a new
snapshot. Historical factor observations may change between published vintages.

`main_jt1993_ff3.py` is offline. Its defaults select the saved original NYSE/AMEX
Table I results, January 1965-December 1989, Panel A, J=6/K=6, and five HAC lags.
Edit `table1_run_tag`, reporting dates, `run_panel`, formation/holding months,
and `run_hac_lags` to select another **already calculated** Table I strategy.
For the recent sample, select its saved Table I run and use 1990-01-01 through
2024-12-31. Select Panel B for the five-trading-day-gap signal. Changing HAC lags
to 12 creates a separate sensitivity result folder. The factor file is shared
by all samples; no new download is needed if the cache covers the selected dates.

The regression is:

```text
winner_minus_loser = alpha + beta_mkt*(Mkt-RF) + beta_smb*SMB + beta_hml*HML + error
```

The risk-free rate cancels between the two portfolio legs. It is retained in
the saved inputs for audit, but it is not subtracted again or used as a fourth
regressor. Missing/duplicate return months or missing factor regressors cause
an error; the run never silently drops calendar months.

OLS and Newey-West inference use NumPy and the existing project dependencies.
Covariance uses Bartlett weights and the n/(n-4) correction. Coefficient/SE
ratios are reported as HAC t-statistics, with **two-sided asymptotic normal**
p-values and 95% confidence intervals. Five lags is a documented baseline
choice, not a requirement imposed by the homework.

Outputs under `results/jt1993/ff3/<run tag>/`:

- `ff3_coefficients.csv`: full-precision estimates, HAC SEs, t-statistics,
  p-values, and 95% intervals. Alpha is a decimal monthly return.
- `ff3_monthly_regression.csv`: aligned portfolio/factor returns, fitted values,
  and residuals, all in decimal units.
- `ff3_hac_covariance.csv` and `run_info.json`: covariance, sample/settings,
  input checksums, factor provenance, N, and R-squared.
- `reports/ff3.csv` and `reports/ff3.html`: plain display-ready tables. Alpha and
  its SE/interval are shown in **percent per month**; loadings are dimensionless.

Set `run_regression=False` to regenerate only the standalone report. This
workflow does not edit or regenerate the homework submission.
