Table I · Returns of relative strength portfolios
J is the formation horizon and K is the holding horizon, both in months. Sell is the lowest
past-return decile, Buy is the highest, and Buy–Sell is the zero-cost winner-minus-loser spread.
Sample and portfolio construction
The sample uses historical NYSE/AMEX classifications (exchange codes 1/2) and common shares
(share codes 10/11). Monthly stock returns are compounded from CRSP daily returns. Ranking uses
information available before the holding period. Stocks are assigned to past-return deciles,
with equal stock weights rebalanced monthly within fixed formation cohorts.
Table I equally weights K active cohorts. Panel A uses contiguous ranking and holding periods;
Panel B implements a one-week gap as five trading days. Earlier data initialize rankings and
overlapping positions before January 1965. Missing holding returns are excluded from cohort
means, and no separate delisting-return adjustment is added in this legacy-data baseline.
Five trading days, the ranking tie rule, and missing-return handling follow the supplied notebook
conventions. These details are not all fully specified by the paper. The comparisons below use
the paper’s published numbers, independently of the notebook benchmark.
All 32 of the 32 calculated Buy–Sell means are positive;
31 have positive returns with conventional |t| ≥ 1.96. The (6,6) Panel A return is
0.88% per month versus 0.95% in the paper, a difference of -7.06 bp/month.

Q1-1 / Event-time performance
Table VII · Performance after portfolio formation
Stocks are ranked using six months of past returns. Each winner-minus-loser formation cohort
is followed for 36 months. These are event-time cohort returns, distinct from Table I’s
overlapping calendar-time strategy returns.
Draft endpoint and inference conventions. The replication uses
265 formation cohorts from January 1965 through January 1987, each with all 36 calendar
holding months inside the window ending December 1989. This is a calendar cutoff, not a requirement
that individual stocks survive. Cumulative returns sum monthly spreads. Monthly t-statistics are
conventional; cumulative t-statistics use Newey–West with Bartlett weights, n/(n−1) correction,
and lags equal to horizon minus one. The paper specifies autocorrelation-consistent cumulative inference
but does not fully specify the endpoint policy or these standard-error settings.

Q1-4 / Sample filters
Sample-selection and data-availability rules
The baseline replication uses CRSP ordinary common shares listed on the NYSE and AMEX.
Following the supplied WRDS reference implementation, the following sample-selection and
data-availability rules are applied:
Exchange membership. Eligible observations have exchange codes
EXCHCD = 1 or 2. Exchange membership is determined using the historical
classification valid on each observation date.
Security type. The sample is restricted to ordinary common shares with
SHRCD = 10 or 11. This restriction excludes American Depositary Receipts (ADRs)
and securities classified by CRSP as real estate investment trusts (REITs). ADR classifications
include share codes 30 and 31, while REIT classifications include codes 18 and 48. These
restrictions follow CRSP’s share-code definitions.
Sample period. Reported portfolio returns cover January 1965 through
December 1989. Earlier observations, beginning in July 1962, supply the return history
required for portfolio ranking and overlapping holding cohorts.
Availability of ranking returns. For Table I, Panel A, a stock must have
valid returns for J consecutive months preceding portfolio formation. For Panel B,
the ranking window excludes the five trading days immediately preceding the holding month.
A stock’s observed history must span the relevant ranking window and contain at least one
valid daily return within it. Stocks without a valid ranking signal are excluded from that
formation’s portfolios.
Return validity. Missing, nonfinite, and below −100% returns are treated
as unavailable; valid −100% returns are retained. Missing monthly ranking returns are not
replaced with zero. During the holding period, portfolio averages are calculated using
constituents with available returns.
Additional availability requirements apply to Tables II and VII. For Table II, market
capitalization is calculated using finite, positive absolute prices and shares outstanding.
Observations with unavailable capitalization are omitted from size calculations while
remaining eligible for return portfolios. For Table VII, formation cohorts are selected to
provide complete 36-month calendar follow-up windows within the sample. This requirement
applies to cohort timing and does not require every constituent stock to survive for 36 months.
Q1-5 / Risk-adjusted momentum returns
Does momentum retain a positive FF3 alpha?
The (6,6) Panel A winner-minus-loser strategy is evaluated
using NYSE/AMEX stocks over January 1965–December 1989, with 300 monthly observations.
Its monthly spread return is regressed on the Fama-French market, size, and value factors:
RW,t − RL,t = α + βM(RM,t − Rf,t)
+ s SMBt + h HMLt + εt.
The dependent variable is the zero-cost spread return. The risk-free rate cancels between
the two portfolio legs, so it is not subtracted again. Monthly US factors are obtained from the
Kenneth French Data Library and aligned with the
holding-return month. All regression inputs are expressed in decimal return units.
